# 模型集成对话平台（Open WebUI）项目说明文档

> 本文档基于本地源码 v0.11.0 版本梳理，仅作为开发与维护参考。

## 一、项目概述

### 1.1 项目简介

本项目是 Open WebUI 的本地化部署实例，对外展示名为「**模型集成对话平台**」。它是一个可扩展、功能丰富、支持离线运行的自托管 AI 平台，用于对接 Ollama、OpenAI 兼容 API 等 LLM 后端，并内置 RAG 推理引擎、工具调用、代码执行、知识库等高级能力。

### 1.2 核心定位

- **统一接入**：一个界面同时管理 Ollama 本地模型、OpenAI 兼容远程模型、第三方工具服务器。
- **私有可控**：所有数据存储本地，会话、文件、向量库均可自托管。
- **可扩展**：通过 Functions / Tools / Skills / Pipelines 等机制扩展功能，无需改动主框架。
- **多用户协作**：内置用户/分组/权限/通道（Channel）体系，可团队部署。

### 1.3 关键标识

| 项 | 值 |
|---|---|
| 内部项目名 | `open-webui` |
| 显示名（品牌） | 模型集成对话平台 |
| 版本 | 0.11.0 |
| 默认开发端口 | 前端 5173 / 后端 8080 |
| 默认生产端口 | 8080 |

## 六、关键配置说明

### 6.1 环境变量（`.env`）

| 变量 | 默认值 | 说明 |
|---|---|---|
| `OLLAMA_BASE_URL` | `http://localhost:11434` | Ollama 后端地址 |
| `OPENAI_API_BASE_URL` / `OPENAI_API_KEY` | 空 | OpenAI 兼容 API |
| `CORS_ALLOW_ORIGIN` | `*` | 跨域（生产应改窄） |
| `ENABLE_PLUGINS` | `true` | 是否启用工具/函数 |
| `ENABLE_MEMORY_SYSTEM_CONTEXT` | `true` | 记忆是否注入系统上下文 |
| `FORWARDED_ALLOW_IPS` | `*` | 反代 IP 白名单 |
| `WEBUI_SECRET_KEY` | 自动生成 | JWT 密钥 |
| `WEBUI_NAME` | `模型集成对话平台` | 平台名（env.py 默认值） |

### 6.2 品牌名控制链路

前端 `APP_NAME`（`src/lib/constants.ts`）只是初始默认值，运行时会被后端 `/api/config` 返回的 `name` 字段覆盖（见 `src/routes/+layout.svelte` 中的 `WEBUI_NAME.set(backendConfig.name)`）。因此修改品牌名必须同时改：

1. 后端 `backend/open_webui/env.py` 的 `WEBUI_NAME` 默认值
2. 前端 `src/lib/constants.ts` 的 `APP_NAME`（用于未拉取后端 config 前的初始化）
3. 硬编码品牌名处（如 `OnBoarding.svelte`）

### 6.3 国际化（i18n）

- 资源目录：`src/lib/i18n/locales/<locale>/translation.json`
- 默认中文环境使用 `zh-CN`，繁体使用 `zh-TW`
- 前端通过 `$i18n.t('key')` 调用，支持插值：`$i18n.t('Hello, {{name}}', { name: 'mzh' })`
- 修改文案只需改对应 key 的译文值

## 七、启动与调试

### 7.1 开发模式（本地当前用法）

```powershell
# 后端（在 backend/ 目录）
$env:WEBUI_SECRET_KEY="<your-secret>"
..\..\.venv\Scripts\python.exe -m uvicorn open_webui.main:app --port 8080 --host 0.0.0.0 --reload

# 前端（在项目根目录）
npm run dev
```

- 前端：http://localhost:5173（Vite dev + HMR）
- 后端：http://localhost:8080（uvicorn + reload）
- 健康检查：http://localhost:8080/health 应返回 `{"status":true}`

### 7.2 HMR 注意事项

修改 i18n JSON 文件后，Vite HMR 偶尔会出现模块导入中断（控制台大量 `net::ERR_ABORTED`）。出现时执行一次硬刷新（URL 加 `?v=N` 递增）即可恢复，无需重启服务。

### 7.3 常用 npm 脚本

| 命令 | 说明 |
|---|---|
| `npm run dev` | 启动前端开发服务器（含 Pyodide 资源拉取） |
| `npm run build` | 生产构建 |
| `npm run check` | Svelte 类型检查 |
| `npm run lint` | 前后端全量 lint |
| `npm run i18n:parse` | 重新解析 i18n 键 |

### 7.4 后端重载

后端以 `--reload` 启动，修改 `backend/open_webui/` 下 Python 文件会自动触发重载。重载期间会重新加载 SentenceTransformer 嵌入模型（约 5-10 秒），完成后 `/health` 恢复 200。

## 八、扩展机制

### 8.1 Functions

全局可注入逻辑，分三类：
- **Filter**：拦截请求/响应，改写消息内容
- **Pipe**：接入额外模型后端（实现 `pipe()` 方法）
- **Action**：响应事件触发

注册路径：管理员后台 → Functions。代码注入到 `open_webui.utils.plugin`。

### 8.2 Tools / Skills

- **Tools**：单条工具调用，对接 OpenAPI 服务器或 MCP 服务器
- **Skills**：组合多个工具的复杂能力

### 8.3 Pipelines

独立插件框架，可部署为单独服务，通过 `/api/v1/pipelines` 接入。

## 十、安全注意事项

1. **生产环境务必改窄 `CORS_ALLOW_ORIGIN`**（默认 `*` 不安全）
2. `WEBUI_SECRET_KEY` 必须保密，不可提交到代码库
3. 反代部署时设置 `FORWARDED_ALLOW_IPS` 为反代 IP
4. 启用 OAuth/LDAP/SCIM 时仔细审查回调 URL 与作用域
5. 文件上传默认存本地 `data/uploads/`，生产建议切换 S3/GCS 并启用私有 Bucket
