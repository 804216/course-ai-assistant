# 课程知识库与 AI 助教验收说明

审计对象为当前活动构建 `20260904-v3` 和 Open WebUI 中的 `Python程序设计基础 AI 助教（LangGraph）`。

## 课程知识库

| 要求 | 当前实现 | 结论 |
| --- | --- | --- |
| 不少于 8 个资料文件，或不少于 30 页 | 160 个源文件，包含 46 个 PDF 和 114 个 Python 文件 | 满足 |
| 按章节或知识模块分类 | 课程说明作为第 0 章，第 1—15 章分别保存文件、知识块和章节元数据 | 满足 |
| 至少 3 类资料 | 讲义 15 个、习题题目 15 个、示例代码 114 个、教学大纲 1 个；另有 15 个受控答案文件 | 满足 |
| 优先依据知识库回答 | 课程问答、概念解释和答案点评均先执行向量 + BM25 + RRF + BGE 重排检索 | 满足 |
| 提供来源或引用 | 知识回答使用 `[资料N]` 行内引用并追加文件名；PDF 标注页码，代码标注行号 | 满足 |
| 未找到信息不得编造 | 证据门控不足时扩展查询一次；仍不足则固定说明“根据现有课程资料无法确认” | 满足 |

活动知识库共有 789 个核心知识块和 137 个受控答案知识块。学生问答默认只访问核心集合，参考答案集合不默认绑定，以降低直接泄露教材答案的风险。

## Open WebUI 课程智能体

前端可选择的 LangGraph Pipe 模型 ID 为 `python_course_langgraph`；同时保留原生对照模型 `python-course-ai-optimized`，不会影响 Open WebUI 的其他模型和知识库。

| 功能要求 | 实现方式 | 结论 |
| --- | --- | --- |
| 课程知识问答 | 核心知识库混合检索、重排、证据门控和多证据回答 | 满足 |
| 通俗解释知识点 | `concept_explain` 分支先作通俗解释，再给正式概念和示例 | 满足 |
| 根据学生水平调整难度 | 识别零基础、初学者、进阶学习者、备考复习四档，并注入不同讲解策略 | 满足 |
| 例题、代码或解题思路 | 根据问题和知识库证据给出小型示例；作业优先给提示和步骤 | 满足 |
| 按章节生成练习 | `practice_tool` 只从指定章节题目材料抽题或生成同类题，每次 1—5 道 | 满足 |
| 分析学生答案 | 必须先收到学生尝试，再按正确之处、存在问题、改进建议、自我检查反馈 | 满足 |
| 提供知识来源 | 引用守卫校验 `[资料N]`，再输出真实文件、页码或代码行号 | 满足 |
| 超出课程范围时提示 | `out_of_scope_response` 明确说明超出《Python程序设计基础》范围 | 满足 |

## 系统提示词与学术诚信

系统提示词明确规定助教身份、课程第 1—15 章范围、默认回答结构、引用规则、证据不足处理以及学术诚信要求。课程策略不可被前端附加的 system 消息覆盖。

对于整份作业、整套习题或可直接提交报告的代做请求，图在知识检索与答案生成前执行确定性拦截。学生可以选择单题并提交已有答案、代码或卡住的步骤，助教再提供提示、思路、分步骤指导和自检方法。

## 自动验证

`tools/course_kb/validate_course_kb.py` 会检查文件数量、资料类型、章节分类、提示词必备条款、向量和目录一致性，以及 Open WebUI 注册状态。`tools/course_agent/smoke_test_langgraph.py` 会真实验证问答、引用、连续上下文、难度适配、章节练习、答案点评、越界提示和学术诚信拦截。
