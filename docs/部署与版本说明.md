# 部署与版本说明

> 本文记录正式部署机的系统信息，由部署维护者更新；信息变化时同步修改本文件。
> 最近更新：2026-09-04

## 基础项目

- 项目：Open WebUI（开源 AI 对话与工具平台）
- 版本：v0.11.0
- 官方仓库：https://github.com/open-webui/open-webui
- 官方文档：https://docs.openwebui.com

## 正式部署机（当前即仓库所在本机）

- 项目目录：`D:\NKSX\course-ai-assistant`
- Open WebUI 源码：`open-webui\`（v0.11.0 快照）
- 运行时数据：`open-webui\local-deploy\data\`。默认不入库；仅提交课程知识库 v3 和与其匹配的嵌入模型快照，`webui.db`、uploads、其他缓存仍不入库
- 知识库数据源：`D:\NKSX\data\`；首次部署时将其完整复制到上述运行时数据目录，源目录保留不动
- 日志和临时文件：`open-webui\local-deploy\logs\`、`open-webui\local-deploy\tmp\`——**不包含额外的 `runtime` 目录层级**
- Python 环境：复用 `open-webui\.venv\`（当前为指向既有虚拟环境的目录联接，不重复安装依赖）
- 访问地址：本机 `http://localhost:8080`；组员共享地址待开放后填写
- 启动方式：
  1. 首次部署或前端代码变化后，运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-open-webui-windows.ps1 -BuildFrontend`；
  2. 已有有效前端 build 时，运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-open-webui-windows.ps1`；
  3. 脚本设置 `DATA_DIR`、`FRONTEND_BUILD_DIR`、`WEBUI_SECRET_KEY` 和本地模型缓存参数，并将缓存、日志及临时文件统一保存在 `open-webui\local-deploy\` 下；
  4. 密钥保存在 `open-webui\local-deploy\webui_secret_key.txt`，该文件不入库。

## 模型接入

- 对话模型：DeepSeek（OpenAI 兼容方式）
  - API Base URL：`https://api.deepseek.com`
  - 当前可用/使用模型：`deepseek-v4-flash`（deepseek-chat 系列）
  - API Key：仅在本机 Open WebUI 管理界面（设置 → 外部连接）中配置，**不写入仓库、不写入本文档**
- 备用连接：OpenAI 兼容入口已配置但本仓库不记录密钥；
- Ollama：配置保留但本机当前未安装运行 Ollama。

## RAG / 知识库

- 嵌入引擎：Default（SentenceTransformers，本地运行，不消耗 API token）
- 嵌入模型：`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`（中文检索；完整可用快照通过 Git LFS 随功能分支提供，位于 `open-webui\local-deploy\data\cache\huggingface`，部署时关闭自动更新并直接离线复用）
- 分块与检索参数：chunk_size=1000、chunk_overlap=100、top_k=3；已关闭“PDF 提取图片”（避免 PPT 转 PDF 中异常图片导致解析崩溃）
- 课程助教向量库：Chroma v3，位于 `open-webui\local-deploy\data\course_kb\builds\20260904-v3\vector_db`；通过相对路径清单定位，可随仓库移动
- 上传文件：`open-webui\local-deploy\data\uploads`
- 元数据/状态：`open-webui\local-deploy\data\webui.db`
- 知识库现状（2026-09-03）：工作区知识库“Python程序设计”，169 个文件处理完成并关联（讲义、习题题目/答案 PDF、教学大纲、示例代码等）；该库向量集合约 1.5 万条向量
- 直接部署：使用 Git LFS 完整克隆功能分支后，仓库已包含课程知识库 v3 和匹配的嵌入模型，无需从 Hugging Face 另行下载模型，也无需重新切分或向量化；启动 Open WebUI 后执行 `scripts\integrate-course-kb-windows.ps1` 注册知识库、课程工具和两个新助教
- 仅在课程源资料发生变化时，才运行 `scripts\build-course-kb-windows.ps1` 生成新的知识库版本

## 更新流程

1. 组员将代码/文档改动推送到本仓库；
2. 部署维护者在部署机拉取代码；
3. 按改动类型重启 Open WebUI 或重新加载；
4. 全组通过共享地址验证。
