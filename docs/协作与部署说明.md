# 协作与部署说明

## 协作模式

1. 正式部署机：成员1 的电脑，运行全组共享的 Open WebUI；
2. 其他成员通过浏览器访问共享地址，不需要各自部署正式系统；
3. 知识库上传、AI 助教创建等网页操作直接在共享系统上完成；
4. 涉及代码的改动：个人在本地开发/测试 -> 推送本仓库 -> 成员1 在部署机更新并重启；
5. 仓库内的文档与系统实际配置保持一致：系统改完后，把最终版本同步回仓库对应文件。

## 需要本地环境的情况

- 负责自定义扩展的成员：本地运行工具脚本即可，多数情况不需要整套 Open WebUI；
- 只有要修改 Open WebUI 自身源码的成员才需要搭本地开发环境。

## 部署记录

- 运行方式：本机源码 + local-deploy 数据目录（`open-webui\local-deploy\data`）
- 访问端口：8080
- 部署机访问地址：`http://localhost:8080`（本机使用）
- 组员访问地址：暂未开放（后续可通过校园网 IP 或 Tailscale 开放）
- Windows 防火墙：已放行 8080；若改为远程访问需确认防火墙/校园网隔离情况

## 网络方案

- 当前：本机使用，组员暂未远程访问；
- 后续若开放：连同一校园网用部署机 IP 访问，或使用 Tailscale 组虚拟局域网。
