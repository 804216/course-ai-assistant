## 一句话协作模式

- **代码与文件**：通过本 Git 仓库同步，成员各自改分支，完成后合并到 `main`。
- **Open WebUI 配置**（知识库、AI 助教等）：直接在共享部署机上操作，全组通过同一网址访问。
- **生效链路**：个人本地测试 -> 推送 Git -> 部署机拉取并重启 -> 全组访问共享地址验收。
