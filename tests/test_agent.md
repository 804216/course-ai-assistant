**测试输入**

>
> 解释：
>
> - **可变性**：列表属于可变序列，可以用 append()、extend()、insert() 添加元素，用 del、remove()、pop() 删除元素，也支持用切片修改元素 [资料1]。元组属于不可变序列，不能增删改元素，也没有相关方法 [资料1]。字典是可变序列，支持通过 dictname[key]=value 添加或修改，用 del 删除键值对 [资料5]。字典的键必须不可变且唯一，因此列表不能作键，元组可以 [资料1][资料2]。

> - **适用场景**：列表适合需要频繁增删改且保持顺序的数据；元组适合只需遍历、保护数据不被修改，或作为字典键使用；字典适合保存具有映射关系的数据，如课程成绩与课程名称的对应 [资料2][资料5]。
>
> 选择建议：需要按位置修改和存储时选列表；数据只读、需要更快访问速度或作为键时选元组；需要按某个键快速查找值时选字典 [资料1][资料2]。

>
> **步骤或思路**
>
> 1. 读文件函数：以 `"r"` 模式打开文本，读取全部内容。
> 2. 统计函数：对每个词执行 `counts[word] = counts.get(word, 0) + 1`。中文分词可参考 `jieba.cut`。
> 3. 写文件函数：以 `"w"` 模式打开结果文件，逐行写出单词和次数。
> 4. 主流程：在 `try` 中依次调用，`except` 捕获 `FileNotFoundError` 等异常。
>
> **伪代码（仅示意，不可直接提交）**
>
> ```python
> def read_file(path):
>     with open(path, "r", encoding="utf-8") as f:
>         return f.read()
>
> def count_words(text):
>     counts = {}
>     for w in text.split():
>         if len(w) == 1:
>             continue
>         counts[w] = counts.get(w, 0) + 1
>     return counts
>
> def write_result(counts, out):
>     with open(out, "w", encoding="utf-8") as f:
>         for w, c in counts.items():
>             f.write(f"{w}\\t{c}\\n")
>
> def main():
>     try:
>         text = read_file("in.txt")
>         counts = count_words(text)
>         write_result(counts, "out.txt")
>     except Exception as e:
>         print("Error!", e)

## 后续优化优先级

1. 增加课程版本事实修正层：教材与现代 Python 行为不一致时，同时给出“教材口径”和“当前版本口径”。
2. 将长度要求、严格列表格式和答案点评四段式加入输出校验，而不只依赖提示词。
3. 对作业型综合任务降低代码生成完整度：首轮只给步骤、接口和关键提示，收到学生尝试后再逐步展开。
4. 增加“目录精确存在性查询”，区分资料不存在、答案集合受控、当前用户无权访问三种状态。
5. 对无答案问题过滤无关候选，避免在拒答说明中罗列不相干章节。
